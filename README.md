# appMonetizar

Plataforma multicanal para planificar, generar, validar, renderizar, aprobar, publicar y medir contenido audiovisual original asistido por IA.

La solución usa arquitectura vertical en .NET, automatización con n8n y contratos reutilizables de `christyepez/CodexCommonAgents`.
